除法的基本定义

除法是什么

  • 已知两个因数的积与其中一个因数，求另一个因数的运算，叫做除法。
  • 在整数除法中，存在整除和不能整除两种情况。
  • 不能整除时，需要用余数描述没有被除数整除的部分。

四个基本量

设：


a：被除数
b：除数
q：商
r：余数

必须满足：


b != 0

基本关系：


a=bq+r

余数范围：


|r|<|b|

基本关系的变形

由：


a=bq+r

可以得到：


r=a-bq
q=(a-r)/b

当 q≠0 时，还可以得到：


b=(a-r)/q

C 语言中的有符号整数除法

现代 C 语言的有符号整数除法采用向 0 截断：


-7 / 2 = -3

根据 r=a-bq：


r = -7 - 2 * (-3)
r = -1

所以 C 语言采用的表示是：


-7 = 2 * (-3) + (-1)

余数符号

在 C 的向 0 截断规则下：

  • 余数为零，或者余数符号与被除数相同。
  • “余数符号跟第一个数有关”中的“第一个数”应准确写成“被除数”。
  • 余数符号不是由除数决定的。

例如：


 7 除以  2：商  3，余数  1
-7 除以  2：商 -3，余数 -1
 7 除以 -2：商 -3，余数  1
-7 除以 -2：商  3，余数 -1

有符号与无符号除法

同类型运算

在常见的 32 位 int、unsigned int 环境中：

| 被除数 | 除数 | 运算采用的类型 | 商的类型 | |---|---|---|---| | 有符号 | 有符号 | 有符号 | 有符号 | | 无符号 | 无符号 | 无符号 | 无符号 |

混合类型运算

当同级别的 int 和 unsigned int 混合时，通常会先把 int 转换为 unsigned int：

| 被除数 | 除数 | 常见转换结果 | 商的类型 | | ------------------ | ------------------ | ---------- | ---- | | 有符号 int | 无符号 unsigned int | 有符号数转为无符号数 | 无符号 | | 无符号 unsigned int | 有符号 int | 有符号数转为无符号数 | 无符号 |

例如：


-7 / 2u

这里的 -7 通常先转换成一个很大的无符号数，因此结果不再是 -3。

向下取整与向上取整

符号与函数名


floor(x) = ⌊x⌋：向下取整，也叫地板取整
ceil(x)  = ⌈x⌉：向上取整，也叫天花板取整

向下取整

⌊x⌋ 表示不大于 x 的最大整数。

例如：


⌊3.7⌋  = 3
⌊-3.7⌋ = -4

向上取整

⌈x⌉ 表示不小于 x 的最小整数。

例如：


⌈3.7⌉  = 4
⌈-3.7⌉ = -3

取整定理与推导

定理 1：基本范围

若 x 为实数：


⌊x⌋≤ x

⌈x⌉≥ x

推导 1：完整范围


x-1 < ⌊x⌋ ≤ x ≤ ⌈x⌉ < x+1

推导 2

由 x-1<⌊x⌋，两边加 1：


x<⌊x⌋+1

推导 3：非整数时上下取整相差 1

当 x 不是整数时：


⌈x⌉=⌊x⌋+1

只有在 x 不是整数时才能直接加 1。

定理 2：整数的上下取整

若 x 是整数：


⌊x⌋=x

⌈x⌉=x

因此当 x 是整数时，上下取整相等，而不是相差 1。

定理 3：正负对称关系


-⌊x⌋=⌈-x⌉

-⌈x⌉=⌊-x⌋

推导 4：对称关系的等价写法


⌊x⌋=-⌈-x⌉

⌈x⌉=-⌊-x⌋

定理 4：加整数后的平移

若 x 为实数，n 为整数：


⌊x+n⌋=⌊x⌋+n

⌈x+n⌉=⌈x⌉+n

这里必须要求 n 是整数。

推导 5：与整数边界比较

若 n 是整数：


⌊x⌋ < n ⇔ x < n

正向证明：

  • 因为 ⌊x⌋≤ x。
  • 若 x

反向证明：

  • 若 ⌊x⌋
  • 又因为 x<⌊x⌋+1。
  • 因此 x

推导 6：加一个很小的数不跨过整数边界

设 a、b 为整数，b≠0，x 为实数。

若：


0≤ x< 1/b

则：


⌊a/b+x⌋ = ⌊a/b⌋

若：


-1/b < x ≤ 0

则：


⌈a/b+x⌉ = ⌈a/b⌉

原因：

  • a/b 的小数部分只能按照 1/|b| 的整数倍变化。
  • 增加或减少一个绝对值小于 1/|b| 的量，不足以跨过下一个整数边界。

推导 7：上下取整公式的互换

当 b > 0 时的正确结论


⌊a/b⌋ = ⌈(a-b+1)/b⌉

⌈a/b⌉ = ⌊(a+b-1)/b⌋

从推导第一个公式


设：

a = qb+r

因为 b>0，可以取：

0≤ r ≤ b-1

所以：

⌊a/b⌋ = q

由余数范围：

0≤ r≤ b-1

两边减去 b-1：

-(b-1) ≤ r-b+1 ≤ 0

因为 b>0，两边除以 b：

-1 < (r-b+1)/b ≤ 0

两边加上整数 q：

q-1 < q+(r-b+1)/b ≤ q

位于区间 (q-1,q] 内的数向上取整等于 q：

q = ⌈q+(r-b+1)/b⌉

代入 a=qb+r：

q+(r-b+1)/b = (qb+r-b+1)/b = (a-b+1)/b

最终得到：

⌊a/b⌋=⌈(a-b+1)/b⌉

从推导第二个公式


仍然设：

a=qb+r， 0≤ r≤ b-1

当 r=0 时：

⌈a/b⌉=q

当 r>0 时：

⌈a/b⌉=q+1

观察：

(a+b-1)/b = q+(r+b-1)/b

当 r=0 时：

0≤(b-1)/b<1

向下取整得到 q。

当 r>0 时，因为余数是整数：

1≤ r≤ b-1

所以：

1≤(r+b-1)/b<2

向下取整得到 q+1。

因此：

⌈a/b⌉ = ⌊(a+b-1)/b⌋

当 b < 0 时

令：


c = -b

因为 b<0，所以 c>0，并且：


a/b = -a/c

利用：


⌊-x⌋ = -⌈x⌉

⌈-x⌉ = -⌊x⌋

可以得到：


⌊a/b⌋ = ⌈(a-b-1)/b⌉

⌈a/b⌉ = ⌊(a+b+1)/b⌋

无符号数除以正的 2^n

若 x 是无符号整数：


x/(2^n) = x >> n

例如：


13 / 8 = 1
13 >> 3 = 1

因为：


8 = 2^3

所以除以 8 对应右移 3 位。

有符号数除以正的 2^n

最终公式


x/(2^n) = (x + ((x >> 31) & (2^n - 1))) >> n

除以 2 的情况

令 n=1：


2^1-1=1

因此：


(x + ((x >> 31) & 1)) >> 1

以 x=-7 为例：


x >> 31 = -1
-1 & 1 = 1
(-7 + 1) >> 1
= -6 >> 1
= -3

结果与 C 的 -7 / 2 相同。

除以 8 的情况

令 n=3：


2^3-1=7

因此：


(x + ((x >> 31) & 7)) >> 3

例如 x=-9：


x >> 31 = -1

-1 & 7 = 7

(-9 + 7) >> 3 = -2 >> 3 = -1

结果与 C 的 -9 / 8 相同。

有符号数除以负的 2^n

最终公式


x/(-2^n) = -((x + ((x >> 31) & (2^n - 1))) >> n)

先计算：


trunc(x/(2^n))

再对商取负：


trunc(x/(-2^n))=-trunc(x/(2^n))

除以 -8 时：


-((x + ((x >> 31) & 7)) >> 3)

例如 x=-9：


-9 / -8 = 1
-((-9 + 7) >> 3)
= -(-2 >> 3)
= -(-1)
= 1
