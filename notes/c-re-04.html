2. 非 2 的幂

$$ 给你一份实战速查表，按"看到什么 → 是什么 → 怎么还原"组织： # 取模逆向速查表 ## 一、模 2 的幂（看掩码识 n） | 场景 | 汇编指纹 | 说明 | |---|---|---| | 无符号 | and reg, 2ⁿ−1（就一条） | 没有任何符号处理 | | 有符号·形态A（cdq 流，你笔记 04.md 那种） | cdq → and edx, 2ⁿ−1 → add eax, edx → and eax, 2ⁿ−1 → sub eax, edx | 加符号掩码补偿后再减回去 | | 有符号·形态B（分支流，你在靶程序遇到的） | and reg, 0x80000000+(2ⁿ−1) → jns → dec → or reg, ~(2ⁿ−1) → inc | jns 是算法内部符号分支，源码无 if | 掩码对照（背这几个就够）： | 见到的常量 | 身份 | 结论 | |---|---|---| | 3 / 80000003h | 2²−1 / 符号位+掩码 | 模 4 | | 7 / 80000007h | 2³−1 | 模 8 | | 0Fh、1Fh、0FFh | 2ⁿ−1 | 模 16、32、256 | | 0FFFFFFFCh | ~3 | 模 4 的负数修正步 | | 0FFFFFFF8h | ~7 | 模 8 的负数修正步 | 规律：低位连续 1 → 是 2ⁿ−1（掩码）；高位连续 1 → 是 ~(2ⁿ−1)（修正用）。 ## 二、模非 2 的幂（公式：x%c = x − (x/c)·c） 指纹三步曲，按顺序出现： 

① 魔数除法序列        → 先用 03.md 的表认出 x/c
② 商乘回 c            → imul reg, reg, c   或   lea 组合（×7: lea r,[r*8] 再 sub r）
③ 被除数 − 乘回值     → sub
关键捷径：c 在②里以普通立即数原样出现——模非 2 的幂时不用解魔数，直接看乘回来那个数就是除数！ 你靶程序里的实例（pay % 7）： 

imul / 92492493h / add / sar     ; ① pay/7 的魔数
lea  eax, ds:0[ecx*8]
sub  eax, ecx                    ; ② 商×7（8q−q 的 lea 玩法）
sub  edi, eax                    ; ③ pay − q×7 = pay%7
## 三、判别口诀 1. 见小掩码（3/7/F/FF…）→ 模 2 的幂；光杆 and 是无符号，带 cdq 尾巴或 8000_000x+dec/or/inc 尾巴是有符号 2. 见魔数别急着喊除法——往后看三条指令：有"乘回+减"→ 是取模；直接存结果 → 是纯除法 3. 乘回的立即数 = 除数，白送 4. 余数符号跟被除数走（C 向零取整），所以符号修正永远在被除数为负的路径上
