SWITCH：

直接分支：


switch (argc) {
case 1:printf("case 1");break;
case 2:printf("case 2");break;
case 3:printf("case 3");break;
}

做一个表：


switch (argc) {
case 1:printf("case 1");break;
case 2:printf("case 2");break;
case 3:printf("case 3");break;
case 4:printf("case 4");break;
}

做两个表（case值最大间隔小于255）：


switch (argc) {
case 100:printf("case 1");break;
case 101:printf("case 2");break;
case 102:printf("case 3");break;
case 104:printf("case 4");break;
default:printf("default");break;
}

二分法（case值间隔超过255）


switch (argc) {
case 100:printf("case 100");break;
case 200:printf("case 200");break;
case 300:printf("case 300");break;
case 400:printf("case 400");break;
case 500:printf("case 500");break;
case 600:printf("case 600");break;
default:printf("default");break;
}

while与for:


在release里面被优化成 if判断加do-while结构：
int i = 0;
while (i < 10) {
    printf("%d", i);
    i++;
} ;
等价于：
if (i < 10) {
    do {
        printf("%d", i);
        i++;
    }
    while (i < 10);
}

循环优化：



代码外提：
先计算argc / 7 后面就不用重复计算了
int n = 0;
for (int i = 0;i < argc / 7;i++) {
    printf("%d", argc + n);
    n++;
}

强度削弱：
用高效的加法运算替代低效的乘法运算
//强度削弱
int n = 0;
int sum = 1;
for (int i = 0; i < argc; i++) {
    sum += argc; //sum = argc + argc + argc
}
printf("%d", sum);

循环展开：
将多次循环体合并为一次执行
for (int i = 0; i < 3; i++) {
    printf("hello world\n");
}
直接转化为3次printf
