六、代码阅读题（共10分）

阅读以下PE加载器代码片段，回答问题：


PIMAGE_DOS_HEADER pDos = (PIMAGE_DOS_HEADER)lpFileBase;
if (pDos->e_magic != 0x5A4D) return NULL;

PIMAGE_NT_HEADERS pNt = (PIMAGE_NT_HEADERS)(lpFileBase + pDos->e_lfanew);
if (pNt->Signature != 0x4550) return NULL;

DWORD imageSize = pNt->OptionalHeader.SizeOfImage;
LPVOID lpImageBase = VirtualAlloc(NULL, imageSize, MEM_COMMIT | MEM_RESERVE,
                                   PAGE_EXECUTE_READWRITE);

memcpy(lpImageBase, lpFileBase, pNt->OptionalHeader.SizeOfHeaders);

PIMAGE_SECTION_HEADER pSection = IMAGE_FIRST_SECTION(pNt);
for (int i = 0; i < pNt->FileHeader.NumberOfSections; i++) {
    LPVOID dest = (LPVOID)((DWORD)lpImageBase + pSection[i].VirtualAddress);
    LPVOID src = (LPVOID)((DWORD)lpFileBase + pSection[i].PointerToRawData);
    memcpy(dest, src, pSection[i].SizeOfRawData);
}

问题：

1. 这段代码在做什么？（2分）


2. 0x5A4D和0x4550分别代表什么？（2分）


3. SizeOfHeaders包含哪些内容？（2分）


4. 这段代码缺少哪些重要步骤才能让PE正常运行？（至少列举3个，4分）
