位操作

C 逆向

位操作：

| | | | | --------------- | ------------------------------- | ------------------------ | | x & -x | 取最低位的 1 | neg + and | | x & (x-1) | 清掉最低位的 1（判 2 的幂：==0 即 2ⁿ） | lea/dec + and | | x \| (x-1) | 低位填 1 | lea/dec + or | | ~(x \| (x-1)) | 低位 1 及以上掩码 | lea/dec + or + not | | x ^ x | 清零（编译器产生 0 的惯用法） | xor reg, reg |

函数优化：


EBP寻址：保留帧指针，参数通过[ebp+8]、[ebp+C]等固定偏移访问，可读性好但占用一个寄存器。
ESP寻址：省略帧指针以优化性能，但栈指针随压栈/出栈动态变化，导致参数偏移不固定，增加逆向难度。



如何判断有几个参数 和返回值：

cdecl
调用方平栈  观察函数push了几个参数 然后进入函数内部观察用了几个arg

stdcall
被调方平栈 看函数结尾的时候return了多少位 判断出几个参数

fastcall
第一个参数 ecx 第二个参数 edx 多了从右往左入栈  进函数里面看用了ecx和edx没有 如果还有压栈的
就是return的参数+2

总结：逆向的时候判断函数内有没有return平栈，如果有排除cdecl ，然后观察是否使用ecx判断是不是fastcall



在ida中快捷键K就是Convert to stack variable（把操作数转换成栈变量）。

如何识别参数类型：
看汇编怎么用它 执行整数加减则为整型，涉及浮点寄存器操作则为浮点型。

如何判断返回值类型：
整形返回值：32位结果存于EAX，64位结果高位存于EDX、低位存于EAX。
浮点返回值：无论float还是double，结果均存放在协处理器栈顶ST0寄存器中
