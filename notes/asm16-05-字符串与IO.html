8086 字符串操作与 I/O 指令

I/O 端口与 IN/OUT 指令

IN 和 OUT 是 8086 中专用于外设端口（I/O Ports）读写的指令。外设端口是 CPU 架构中专用于硬件设备通信的独立物理/逻辑地址空间，范围 0x0000 ~ 0xFFFF（65536 个），与内存地址空间完全隔离。

独立编址与端口隔离

CPU 通过 M/IO# 引脚区分内存访问和 I/O 访问，拥有两个独立的地址空间：

1. 内存地址空间（Memory Space）：存放代码和数据，寻址指令是常规的 MOV 2. I/O 端口地址空间（I/O Space）：专门用于外围设备，寻址指令是专属的 IN 和 OUT

CPU 如何与外设通信

以从 PS/2 键盘读取一个按键为例：按下键盘时，键盘控制器将按键的扫描码放到它的数据寄存器中，这个寄存器在主板硬件布线上被硬编码分配了端口号 0x60。CPU 不能用 MOV AL, [0x60]（这会去内存的 0x60 处读垃圾数据），必须用专属的输入指令：


IN AL, 0x60   ; 硬件行为：M/IO# 置低 + RD# 置低，通知 0x60 端口的硬件把数据送上数据总线

向显卡发送控制命令（如端口 0x3D4/0x3D5）：


MOV DX, 0x3D4 ; 将 VGA 控制器的索引端口号放入 DX 寄存器
MOV AL, 0x0A  ; 准备发送光标控制命令
OUT DX, AL    ; 硬件行为：M/IO# 置低 + WR# 置低，把 AL 的数据射向显卡

常见硬件端口速查：


IN AL, 0x60        ; 读取键盘扫描码
OUT 0x20, AL       ; 向中断控制器发送 EOI（End of Interrupt）
MOV DX, 0x3F8      ; 串口 COM1
IN AL, DX          ; 从串口读取数据

| 端口号 | 设备 | |--------|------| | 0x60 | 键盘控制器 | | 0x20 / 0xA0 | 中断控制器（主/从） | | 0x3F8 ~ 0x3FF | 串口 COM1 | | 0x3D4 / 0x3D5 | VGA 控制器 |

注意：

  • 不能用 MOV 访问 I/O 端口。MOV AL, [0x60] 访问的是内存地址 0x60，不是 I/O 端口 0x60，两者地址空间完全隔离
  • 8086 实模式下 IN/OUT 没有任何权限限制；Ring 0/IOPL 限制是 286+ 保护模式才引入的，现代用户态（Ring 3）程序强行执行会触发异常

外设端口 vs 网络端口

| 维度 | 外设端口（I/O Port） | 网络端口（Network Port） | |------|-------------------|----------------------| | 层级 | 硬件级别 | 软件协议级别 | | 本质 | CPU 用电信号与主板芯片直接说话的通道 | 操作系统 TCP/IP 协议栈区分网络应用的逻辑编号 | | 范围 | 0x0000 ~ 0xFFFF | 0 ~ 65535 | | 操作指令 | IN / OUT | socket API |

两者数值范围相同但是完全不同的概念：IN/OUT 指令操作的是外设端口（硬件级）；socket API / INT 21h 调用涉及的是网络端口（软件级）。

指令格式与机器码

| 指令 | 机器码 | 说明 | |------|--------|------| | IN AL, imm8 | E4 [imm8] | 从 8 位立即数指定的端口读取 1 字节到 AL | | IN AX, imm8 | E5 [imm8] | 从 8 位立即数指定的端口读取 1 字到 AX | | OUT imm8, AL | E6 [imm8] | 将 AL 写出到 8 位端口 | | OUT imm8, AX | E7 [imm8] | 将 AX 写出到 8 位端口 | | IN AL, DX | EC | 从 DX 指定的端口读取 1 字节到 AL（端口号 > 0xFF 时使用） | | IN AX, DX | ED | 从 DX 指定的端口读取 1 字到 AX | | OUT DX, AL | EE | 将 AL 写出到 DX 指定的端口 | | OUT DX, AX | EF | 将 AX 写出到 DX 指定的端口 |

端口号大于 0xFF 时用 DX

端口号超过 255 时不能直接用立即数寻址，必须先把端口号装入 DX：


; 端口号 ≤ 0xFF：可用立即数
IN AL, 0x60        ; 合法，读取键盘端口

; 端口号 > 0xFF：必须用 DX
MOV DX, 0x3F8      ; 串口 COM1
IN AL, DX          ; 合法
; IN AL, 0x3F8     ; 非法！立即数不能超过 0xFF

C 语言中的端口操作

现代操作系统用户态（Ring 3）下 IN/OUT 被内核封锁，驱动程序开发中用封装好的函数：


// MSVC 下的 Windows 内核驱动
#include <ntddk.h>

void WriteToPort() {
    // 向 COM1 串口 (端口 0x3F8) 发送字符 'A'
    // 编译器底层翻译为：
    //   MOV DX, 0x3F8
    //   MOV AL, 0x41 ('A')
    //   OUT DX, AL
    WRITE_PORT_UCHAR((PUCHAR)0x3F8, 'A');
}

字符串操作指令

8086 提供了一组专门用于操作内存中连续数据块的指令，能够自动递增或递减指针，配合重复前缀（REP）实现高效的批量数据移动、比较、扫描和存储。

共 5 条核心指令：MOVS、CMPS、SCAS、LODS、STOS。

隐含操作数机制

字符串指令使用隐含的寄存器操作数，无需在指令中显式写出：

| 寄存器 | 作用 | |--------|------| | DS:SI | 源地址指针（Source Index） | | ES:DI | 目的地址指针（Destination Index） | | CX | 计数器（重复次数） | | AL/AX | 累加器（用于 STOS/SCAS/LODS 的数据中转） | | DF | 方向标志（Direction Flag），决定 SI/DI 递增还是递减 |

字符串指令是 C 语言内存函数的底层实现：


; memcpy
CLD
REP MOVSB         ; 从 DS:SI 复制到 ES:DI，CX 次

; memset
MOV AL, 0
CLD
REP STOSB         ; 将 ES:DI 指向的内存填充 AL，CX 次

; memcmp
CLD
REPE CMPSB        ; 比较 DS:SI 和 ES:DI，CX 次，相等则继续

注意：MOVS、STOS、SCAS 的目的操作数固定使用 ES:DI，不能通过段超越前缀修改。使用前必须确保 ES 已设置为正确的段地址。源地址默认 DS，可以加段超越前缀。

方向标志 DF 的控制

| DF 值 | 缩写 | 效果 | 适用场景 | |-------|------|------|---------| | DF = 0 | UP | SI/DI 递增（正向） | 字符串从低地址到高地址处理 | | DF = 1 | DN | SI/DI 递减（反向） | 字符串从高地址到低地址处理 |


CLD   ; Clear Direction Flag，DF=0，正向
STD   ; Set Direction Flag，DF=1，反向


; 正向复制（从低地址到高地址）
CLD
REP MOVSB

; 反向复制（从高地址到低地址，用于重叠内存）
STD
REP MOVSB

注意：调用字符串指令前务必用 CLD 或 STD 显式设置 DF，不要假设 DF 的初始状态，否则指针移动方向会错。如果看到字符串指令前没有 CLD/STD，说明代码假设 DF 已是期望状态——这是潜在风险。

重复前缀 REP

REP 前缀使字符串指令自动重复执行，每次执行后 CX 减 1，直到 CX = 0：

| 重复前缀 | 终止条件 | 适用指令 | |---------|---------|---------| | REP | CX = 0 | MOVS、STOS、LODS | | REPE / REPZ | CX = 0 或 ZF = 0 | CMPS、SCAS（相等时继续） | | REPNE / REPNZ | CX = 0 或 ZF = 1 | CMPS、SCAS（不等时继续） |


REP MOVSB         ; 无条件重复，直到 CX=0，批量复制
REPE CMPSB        ; 相等时继续，直到 CX=0 或 ZF=0，找第一个不相等的位置
REPNE SCASB       ; 不等时继续，直到 CX=0 或 ZF=1，找第一个匹配的字符

对应关系：REP + MOVS = memcpy，REP + STOS = memset，REPE + CMPS = memcmp，REPNE + SCAS = memchr/strchr。

注意：如果 CX 初始为 0，REP 前缀的指令一次都不执行，直接跳过。这在循环设计中可能造成逻辑错误。

MOVS — 字符串传送

从 DS:SI 复制一个字节/字到 ES:DI，然后 SI/DI 自动 ±1（字节）或 ±2（字）：


MOVSB   ; ES:[DI] ← DS:[SI]，SI←SI±1，DI←DI±1
MOVSW   ; ES:[DI] ← DS:[SI]，SI←SI±2，DI←DI±2

; 批量传送
LEA SI, SOURCE    ; DS:SI = 源地址
LEA DI, DEST      ; ES:DI = 目的地址
MOV CX, 100       ; 传送 100 个字节
CLD               ; 正向
REP MOVSB         ; 重复执行 100 次

按字传送比按字节快一倍（80386+ 还有 REP MOVSD 32 位优化）：


; 优化前：逐字节复制
MOV CX, 100
REP MOVSB         ; 100 次总线传输

; 优化后：按字复制（长度是偶数时）
MOV CX, 50
REP MOVSW         ; 50 次总线传输，快一倍

CMPS — 字符串比较

比较 DS:SI 和 ES:DI 指向的字节/字，结果影响标志位，SI/DI 自动 ±1 或 ±2：


CMPSB   ; 比较 DS:[SI] 与 ES:[DI]，SI←SI±1，DI←DI±1
CMPSW   ; 比较 DS:[SI] 与 ES:[DI]，SI←SI±2，DI←DI±2

; 比较两个字符串是否相等
LEA SI, STR1
LEA DI, STR2
MOV CX, 10
CLD
REPE CMPSB   ; 相等则继续比较，直到 CX=0 或找到不相等的位置

REPE CMPSB 是 memcmp/strcmp 的汇编实现：终止时要么 CX=0（全部相等），要么 ZF=0（找到不相等的位置），检查 ZF 可以判断比较结果。

注意：CMPS 执行后 SI 和 DI 已自动移动。如果需要重新比较同一个位置，需手动调整 SI/DI。

SCAS — 字符串扫描

将 AL/AX 与 ES:DI 指向的字节/字比较，结果影响标志位，DI 自动 ±1 或 ±2：


SCASB   ; 比较 AL 与 ES:[DI]，DI←DI±1
SCASW   ; 比较 AX 与 ES:[DI]，DI←DI±2

; 在字符串中查找字符 'A'
MOV AL, 'A'
LEA DI, BUFFER
MOV CX, 100
CLD
REPNE SCASB   ; 没找到则继续，直到 CX=0 或找到 'A'

REPNE SCASB 是 strchr/memchr 的实现：终止时要么 CX=0（没找到），要么 ZF=1（找到了）：


MOV AL, 'A'
LEA DI, BUFFER
MOV CX, 100
CLD
REPNE SCASB      ; 没找到则继续
JNE NOT_FOUND    ; 如果 CX=0 且没找到
; 找到：DI 指向目标字符的下一个位置
DEC DI           ; DI 回退到目标字符
NOT_FOUND:

注意：找到匹配字符后，DI 已自动 ±1，指向匹配字符的下一个位置。需要获取匹配字符的地址时必须 DEC DI（正向时）或 INC DI（反向时）。

LODS — 加载字符串

将 DS:SI 指向的字节/字加载到 AL/AX，SI 自动 ±1 或 ±2：


LODSB   ; AL ← DS:[SI]，SI←SI±1
LODSW   ; AX ← DS:[SI]，SI←SI±2

; 遍历字符串并处理每个字符
CLD
NEXT:
    LODSB         ; 加载一个字符到 AL
    OR AL, AL     ; 检查是否为 0（字符串结束）
    JZ DONE
    ; 处理 AL 中的字符...
    JMP NEXT
DONE:

LODSB + STOSB 组合实现自定义字符串处理（大小写转换、编码转换、过滤）：


; 将字符串中的小写字母转为大写
CLD
NEXT:
    LODSB          ; 从源加载一个字符
    OR AL, AL      ; 检查字符串结束
    JZ DONE
    CMP AL, 'a'
    JB  STORE      ; 小于 'a' 的直接存储
    CMP AL, 'z'
    JA  STORE      ; 大于 'z' 的直接存储
    SUB AL, 0x20   ; 小写转大写
STORE:
    STOSB          ; 存储到目的
    JMP NEXT
DONE:

注意：LODS 不改变任何标志位。需要检查加载的值（如判断是否为 0）时，必须手动执行 OR AL, AL 或 TEST AL, AL 来设置标志位。

STOS — 存储字符串

将 AL/AX 存储到 ES:DI，DI 自动 ±1 或 ±2：


STOSB   ; ES:[DI] ← AL，DI←DI±1
STOSW   ; ES:[DI] ← AX，DI←DI±2

; 将 100 字节的缓冲区全部填充为 0
MOV AL, 0
LEA DI, BUFFER
MOV CX, 100
CLD
REP STOSB   ; 重复填充 100 次

REP STOSB 是 memset 的实现：AL 中的值就是要填充的字节。AL=0 是清零缓冲区；AL=0xFF 是将缓冲区全部置 -1（常用于初始化栈或内存池）。

综合示例：C 内存函数的汇编实现

strcpy（以 0 结尾的字符串复制）：


STRCPY:
    LEA SI, SOURCE
    LEA DI, DEST
    CLD
COPY_LOOP:
    LODSB           ; 从源加载一个字节到 AL
    STOSB           ; 将 AL 存储到目的
    OR AL, AL       ; 检查是否为 0
    JNZ COPY_LOOP   ; 不是 0 则继续
    RET

memcpy（尽量按字传送，奇数长度补一个字节）：


; void memcpy(void* dst, void* src, unsigned int len)
; 入口：DI = dst, SI = src, CX = len
MEMCPY:
    CLD
    SHR CX, 1       ; 长度折半（转为字计数）
    REP MOVSW       ; 按字传送，比 MOVSB 快一倍
    JNC NO_BYTE     ; 如果原长度为奇数，CF=1
    MOVSB           ; 补传最后一个字节
NO_BYTE:
    RET

memset：


; void memset(void* buf, unsigned char val, unsigned int len)
; 入口：DI = buf, AL = val, CX = len
MEMSET:
    CLD
    REP STOSB
    RET

memcmp：


; int memcmp(void* a, void* b, unsigned int len)
; 入口：SI = a, DI = b, CX = len
; 出口：AX = 0（相等）或差值
MEMCMP:
    CLD
    REPE CMPSB      ; 相等则继续比较
    JZ  EQUAL
    ; CMPSB 执行后 SI/DI 已越过比较的字节，需回退
    DEC SI          ; SI 回退到不相等字节
    DEC DI          ; DI 回退到不相等字节
    MOV AL, [SI]    ; 取 buf1 的第一个不同字节
    MOV BL, [DI]    ; 取 buf2 的第一个不同字节
    XOR AH, AH      ; 清零 AH，确保 AX 高字节为 0
    XOR BH, BH      ; 清零 BH，确保 BX 高字节为 0
    SUB AX, BX      ; 计算差值
    RET
EQUAL:
    XOR AX, AX      ; 返回 0
    RET

memchr：


; void* memchr(void* buf, unsigned char ch, unsigned int len)
; 入口：DI = buf, AL = ch, CX = len
; 出口：DI = 找到的位置（或 NULL）
MEMCHR:
    CLD
    REPNE SCASB     ; 没找到则继续
    JNZ NOT_FOUND
    DEC DI          ; DI 回退到匹配字符
    RET
NOT_FOUND:
    XOR DI, DI      ; 返回 NULL
    RET

memmove（处理重叠内存：dst < src 正向复制，否则反向）：


; void memmove(void* dst, void* src, unsigned int len)
; 入口：DI = dst, SI = src, CX = len
MEMMOVE:
    CLD
    CMP DI, SI
    JB  FORWARD     ; dst < src，正向安全
    STD             ; 反向：从尾部开始复制
    ADD SI, CX      ; SI 指向源尾部
    DEC SI
    ADD DI, CX      ; DI 指向目的尾部
    DEC DI
    JCXZ DONE       ; CX=0 时跳过复制，避免指针错误调整
    REP MOVSB       ; 反向复制
    CLD             ; 恢复方向标志
    RET
FORWARD:
    REP MOVSB       ; 正向复制
DONE:
    CLD
    RET

memcpy 和 memmove 的区分信号：CMP DI, SI + STD + 尾部指针调整 = memmove。普通 memcpy 不会检查地址重叠，也不会用 STD 反向复制。
