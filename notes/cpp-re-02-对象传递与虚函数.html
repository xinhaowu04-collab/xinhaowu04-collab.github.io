对象传递与虚函数

对象作为函数参数


  按值传参分三档（看是否 trivial，trivial=空操作不生成代码）：
    ① 完全 trivial（POD，无自定义拷贝构造/析构）：
       小对象直接字节拷进栈参区（4/8字节=1~2个push）
       构造/析构调用一个都看不到（trivial 析构不生成代码）

    ② 析构非 trivial、拷贝构造 trivial：
       调用方拷贝一份副本（无显式ctor调用）
       → 被调函数结束时析构这份参数副本
       ★ "函数外构造、函数内析构"

    ③ 有自定义拷贝构造：
       与大小无关，一律走地址：
       调用方抬栈开临时空间 → call 拷贝构造(临时this, &源)
       → 把临时对象地址当参数传入

拷贝构造 vs 移动构造


  拷贝构造：ctor(this, &src)，逐成员赋值，不碰源的指针
  移动构造：源指针成员搬到 this 后，把源指针置空
    → 汇编铁证：源对象 +N 偏移处被写 0，就是 move（资源所有权转移）

对象作为返回值


  生命周期铁律：函数内构造、函数外（调用方作用域）析构
  大对象走隐藏指针返回（调用方开空间、地址当第一参数）
  RVO/NRVO：
    return Point(1,2)（无名临时）：
      直接在调用方给的隐藏指针上原地构造，拷贝构造整个消失
    return 局部命名对象：NRVO（MSVC /O2 常做）同样原地构造
      优化不到才走 拷贝/移动构造 + 析构局部
  识别：调用方析构了一个"自己没构造过"的对象
        （构造发生在被调函数里）→ 返回值对象

虚函数机制


  对象偏移0 = vptr，指向 .rdata 的函数指针数组（虚表）

  构造函数：给 [this+0] 写虚表地址 ← 识别构造的强特征
    有继承时写入多次：先基类虚表后派生虚表
    → 两次 vptr 写入 = 继承链证据

  析构函数：反向恢复，把 vptr 改回基类虚表
  多态调用模板：
      mov  eax, [ecx]          ; 取虚表
      call dword ptr [eax+8]   ; 虚表偏移 4×N（N从0起）

虚表结构与RTTI


  找虚表的锚点：构造函数里 mov [reg], offset 虚表
  槽位惯例：第0/1槽 = 析构代理族（scalar/vector deleting dtor）
            → 认虚表先认析构代理
  边界判断：连续函数指针序列；或借编译器生成的标号

  RTTI（MSVC 默认开 /GR）：
    虚表[-1]（前一格）指向 RTTI Complete Object Locator
    → 顺藤摸到 type descriptor
    → 内嵌类名字符串 .?AV类名@@（含命名空间）
    → 剥掉符号的二进制也能还原类名

  实操：IDA 字符串窗口(Shift+F12) 搜 ".?AV" 扫全程序类名
  vs c/c++ 所有选项 启用运行时类型信息 选择关闭 可关 RTTI；
  但用了 dynamic_cast/typeid 会强制开启
  多继承：对象里有多个 vptr（每个含虚函数的基类一个）
