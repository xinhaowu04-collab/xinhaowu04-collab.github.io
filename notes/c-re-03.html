无符号除为非 2 的幂常量

C 逆向

无符号除为非 2 的幂常量：


c = 2^n / M

设 x 为被除数变量，c 为某一常量，则有：

$$ \begin{aligned} \frac{x}{c} &= x \times \frac{1}{c} \\ &= x \times \frac{1 \times 2^n}{c \times 2^n} \\ &= x \times \frac{2^n}{c} \times \frac{1}{2^n} \end{aligned} $$

由于 c 为常量，且 2 的取值由编译器选择，所以 $2^n/c$ 的值在编译期间可以计算出来。n 的取值在 32 位除法中通常都会大于等于 32，在 64 位除法中通常都会大于等于 64。这样就可以直接调整使用乘法结果的高位了。

如此一来，$2^n/c$ 也就是一个编译期间先行计算出来的常量值了，这个值常被称为 Magic Number（魔数、幻数），我们先用 M 来代替这个 Magic 常量，于是又有：

$$ \begin{aligned} x \times \frac{2^n}{c} \times \frac{1}{2^n} &= xM \times \frac{1}{2^n} \\ &= \frac{xM}{2^n} \\ &= xM \gg n \end{aligned} $$

无符号除为非 2 的幂常量：（M 超过 32 位）：


c = 2 ^ n / (2^32 + M)

x / c = ((x - ((x * M) >> 32)) >> 1) + ((x * M) >> 32) >> 2
$$ c = \frac{2^n}{2^{32}} + M $$
$$ \begin{aligned} \frac{ \frac{ecx-\frac{ecx \times M}{2^{32}}}{2} +\frac{ecx \times M}{2^{32}} }{2^2} &= \frac{ \frac{2^{32}ecx-ecx \times M}{2^{33}} +\frac{ecx \times M}{2^{32}} }{2^2} \\ &= \frac{ 2^{32}ecx-ecx \times M+2 \times ecx \times M }{2^{35}} \\ &= \frac{2^{32}ecx+ecx \times M}{2^{35}} \\ &= \frac{ecx \times (2^{32}+M)}{2^{35}} \\ &= ecx \times \frac{2^{32}+M}{2^{35}} \end{aligned} $$

至此，我们可以看出除法优化的原型，是带进位值的 MagicNumber。编译器作者在实现除法优化的过程中，计算得到的 MagicNumber 超过了 4 字节整数范围，为了避免大数运算的开销，对此做了数学转换，于是得到最开始的表达式，规避了 8 字节的大数计算问题。

有符号除 非 2 的幂常量：


x >= 0
    x / c = (x * M >> n) + 0

x < 0
    x / c = (x * M >> n) + 1

有符号除非 2 的幂常量（M 为负数）：


c ≈ 2^n / (m + 2^32)


x >= 0
    x / c = ((x * M >> 32) + x) >> n - 32 + 0

x < 0
    x / c = ((x * M >> 32) + x) >> (n - 32) + 1

编译器在计算 MagicNumber 时是作为无符号处理的，而代入到除法转换乘法的代码里又是作为有符号乘数处理的。因为有符号数的最高位不是数值，而是符号位，所以，对应的有符号乘法指令是不会让最高位参与数值计算的，这样会导致乘数的数学意义和 MagicNumber 不一致。

于是，在有符号乘法中，如果 M 的取值大于 0x80000000（最高位为 1，补码形式为负数）时，实际参与乘法计算的是个负数，其值应等价于：

$$ \begin{aligned} \frac{x}{c} &= x \times \frac{2^n}{c} \times \frac{1}{2^n} \\ &= x \times \left( \left(\frac{2^n}{c}-2^{32}\right)+2^{32} \right) \times\frac{1}{2^n} \\ &= \left( x\left(\frac{2^n}{c}-2^{32}\right) +x2^{32} \right) \times\frac{1}{2^n} \\ &= \left( \frac{x\left(\frac{2^n}{c}-2^{32}\right)}{2^{32}} +x \right) \times\frac{1}{2^{n-32}} \\ &= \left( \frac{xM}{2^{32}}+x \right) \times\frac{1}{2^{n-32}} \\ &\approx \left( (xM\gg32)+x \right) \gg(n-32) \end{aligned} $$
